## Non-negotiable quality rules
- Build a real, functional website—not a static demo.
- Do not invent projects, achievements, statistics, testimonials, skills, or GitHub activity.
- Mark unknown information as TODO and keep it easy to fill in later.
- Keep content/data separate from reusable UI components.
- Never overwrite or delete existing repository files without explicit approval.
- Test production build, navigation, mobile layouts, accessibility basics, and links before calling the site complete.
