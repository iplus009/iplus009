## Non-negotiable customization rules
- Inspect every available Figma frame before replacing the current visual direction.
- Keep all controls functional; do not add decorative buttons that do nothing.
- Do not invent project outcomes, user metrics, testimonials, employment history, email addresses or social links.
- Keep the owner name as Ismail and GitHub as https://github.com/iplus009 unless the owner changes them.
- Ask before deleting sections or changing project identity.
- Preserve reduced-motion support, semantic HTML, focus visibility and mobile responsiveness.
- Keep the site lightweight unless a framework is justified by a concrete feature.
