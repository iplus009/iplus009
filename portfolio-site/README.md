# Ismail — Portfolio Website

A responsive, dark editorial portfolio starter for Ismail. Built with plain HTML, CSS and JavaScript so another agent can customize it without first setting up a framework or build pipeline.

## Preview locally
Open `index.html` in a browser. No package installation or build step is required.

## Included
- Responsive desktop, tablet and mobile layouts
- Dark graphite visual system with red accent and subtle grid/noise treatment
- Animated hero illustration and orbital details
- Scroll reveal animations using Intersection Observer
- Animated ticker, scroll progress indicator and hover states
- Mobile navigation with accessible expanded state
- Project category filter and accessible project detail dialog
- Reduced-motion support
- SEO description, Open Graph basics and SVG favicon
- GitHub profile link to https://github.com/iplus009

## Before publishing
1. Replace `hello@example.com` in `index.html` with the public contact email.
2. Add the owner's approved profile photo if desired; the current hero artwork is abstract and intentionally does not pretend to be a real portrait.
3. Confirm project descriptions, statuses and public links with the owner.
4. Review the Figma source and refine visual details against the actual frames.
5. Test on real mobile browsers and check keyboard navigation.

## Important
This is a functional front-end foundation, not a backend or CMS. Project content is currently written into the page and project detail data in `script.js`. No fake GitHub activity, fabricated metrics, or made-up contact details are shown.
